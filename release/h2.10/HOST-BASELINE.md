Esta política se aplica al preflight de instalación/continuación; no interlock de arranque automático ni monitor continuo. Validar antes de mantenimiento/arranque controlado. No introducir contenedores ni distribuir rootfs sin necesidad. Python bootstrap conserva limitación histórica: versión y uv wheel pin, no hash completo de distribución preexistente.
